# Front-End Online Store

Loja virtual em React que consome a API pública do Mercado Livre: navegue por categorias, busque produtos, veja detalhes e monte seu carrinho.

> Projeto desenvolvido durante o curso de Desenvolvimento Web da [Trybe](https://www.betrybe.com/) (2023). Projeto em grupo.

## Funcionalidades

- Listagem de categorias e busca de produtos (API do Mercado Livre)
- Página de detalhes do produto
- Carrinho de compras salvo no localStorage, com controle de quantidade
- Página de checkout

## Stack

React 18 · TypeScript · React Router · Vite · Vitest · React Testing Library

## Como rodar

```bash
npm install
npm run dev
```

Testes:

```bash
npm test
```
